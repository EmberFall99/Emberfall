# Emberfall

A low-budget souls-like built in [Microsoft MakeCode Arcade](https://arcade.makecode.com).

Wake in a cell. Fight through the Ashen Gate, the Sunken Hall, the Whispering Woods and the Archers' Rampart, face the Hollow Warden, and find what lies beyond the prison gate – and further east, the ruined village of Ashen Forde.

## Open it in MakeCode Arcade

1. Go to <https://arcade.makecode.com>.
2. Click **Import**, then **Import URL**, and paste this repository's URL.
3. To save your changes back here, sign in to GitHub inside MakeCode and use the GitHub button to commit.

## Controls

| Button | Action |
| --- | --- |
| Left / Right | Move |
| Up | Jump, climb |
| Down | Climb, drink a Cordial, rest at a bonfire |
| B | Roll (invincible for a moment) |
| A (tap) | Attack. Tap A A A for the sword combo |
| A (hold) | Heavy attack / raise shield / power shot / Katana: sheathed charge, let go to dash, depending on loadout |
| A (near someone / a door / a stair) | Talk / read / enter / descend |
| A (as a foe attacks, with the Farsight Amulet) | Parry. Attack again to riposte |
| Menu | Equipment |

## Where things are

| File | What's in it |
| --- | --- |
| `images.g.jres` | All the art. Edit it in the **Assets** tab, not by hand |
| `art.ts` | Collects the assets into variables the code uses |
| `music.ts` | The background music (generated by `tools/make_music.js`) |
| `state.ts` | Every game variable: player, enemies, levels, world |
| `world.ts` | Areas, respawning, resting, dying |
| `player.ts` | Input, combo, shield, bow, riposte, climbing, doors, physics, animation |
| `enemies.ts` | Skeletons, the skeleton knight, archers, corrupted bandits, parrying |
| `boss.ts` | The Hollow Warden |
| `scenery.ts` | Bonfires, key, door, item drops, NPCs, bloodstain, HUD |
| `menus.ts` | Equipment menu (weapons + amulet slot) |
| `levelling.ts` | Stats, bonfire level-up menu, embers |
| `prologue.ts` | The opening text, the falling key, starting in the cell |
| `story.ts` | Dialogue box, fades, Glargon's scene, the note, the uncorrupted bandit |
| `saving.ts` | Saving at bonfires and story moments, loading on Continue |
| `main.ts` | The main loop and game start |
